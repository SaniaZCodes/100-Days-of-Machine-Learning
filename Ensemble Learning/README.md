Ensemble Learning is a machine learning technique that combines multiple models to improve prediction performance.

Main advantages:
- Higher Accuracy
- Better Generalization
- Reduced Overfitting

Main Types:
1. Voting
2. Bagging
3. Boosting
4. Stacking

Random Forest is based on Bagging.

AdaBoost, Gradient Boosting, and XGBoost are based on Boosting.

The core idea of ensemble learning is that a group of models usually performs better than a single model.
