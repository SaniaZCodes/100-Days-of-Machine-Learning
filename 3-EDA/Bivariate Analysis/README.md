# Bivariate & Multivariate Analysis 📊

## What?

### Bivariate Analysis
Analyzing two variables together.

Example:
- Age vs Salary
- Study Hours vs CGPA

### Multivariate Analysis
Analyzing more than two variables together.

Example:
- Age + Salary + Experience
- Study Hours + Attendance + Assignment Marks

---

# Numerical vs Numerical

Examples:
- Age vs Salary
- Study Hours vs CGPA

## Scatterplot 📍
Used to find relationship between two numerical variables.

Question:
→ As one variable increases, does the other increase or decrease?

## Pairplot 📊
Shows relationship between multiple numerical columns together.

Question:
→ Which numerical features are related?

## Lineplot 📈
Shows trend or change over time.

Question:
→ How does a variable change?

---

# Numerical vs Categorical

Examples:
- Salary vs Department
- Marks vs Gender

## Boxplot 📦
Compares numerical values across categories.

Question:
→ Which category has higher values?
→ Are there outliers?

## Barplot 📊
Shows average values for different categories.

Question:
→ Which category performs better?

## Distplot 📈
Compares data distributions between categories.

Question:
→ How is data distributed?

---

# Categorical vs Categorical

Examples:
- Gender vs Department
- City vs Department

## Heatmap 🔥
Shows relationship between categories.

Question:
→ Which combinations occur most frequently?

## Clustered Bar Chart 📊
Compares multiple categorical groups.

Question:
→ How do categories differ from each other?

---

# Easy Examples

Age vs Salary
→ Scatterplot

Gender vs Salary
→ Boxplot

Department vs Department
→ Heatmap

Multiple Numerical Features
→ Pairplot

# Golden Line 🌟

Univariate Analysis = 1 Variable

Bivariate Analysis = 2 Variables

Multivariate Analysis = Multiple Variables
