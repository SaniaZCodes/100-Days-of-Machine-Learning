# Univariate Analysis 📊

## What?

Univariate Analysis means analyzing only one feature (column) at a time.

Uni = One
Variable = Feature

Example:
- Age
- Salary
- Gender
- Marks

---

## Why Do We Use It?

To understand:

✅ Distribution

✅ Missing Values

✅ Outliers

✅ Most Common Values

✅ Data Spread

---

## Numerical Columns

Examples:
- Age
- Salary
- Marks

Graphs Used:

📈 Histogram
→ Shows distribution

📦 Boxplot
→ Detects outliers

📊 Distplot
→ Shows distribution shape

Questions Answered:

- What is the average value?
- Is data normally distributed?
- Are there any outliers?

---

## Categorical Columns

Examples:
- Gender
- Department
- City

Graphs Used:

📊 Countplot
→ Counts categories

📈 Bar Chart
→ Compares categories

Questions Answered:

- Which category is most common?
- Which category is least common?

---

## Easy Example
