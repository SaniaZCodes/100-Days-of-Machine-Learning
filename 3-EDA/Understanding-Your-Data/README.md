# Understanding Your Data 📊
## Overview

Before building any Machine Learning model, it is important to understand the dataset thoroughly. Data understanding is the first step toward effective data analysis, preprocessing, feature engineering, and model building.

## Objectives
In this notebook, I explored the dataset to understand:
- Number of rows and columns
- Feature names
- Data types
- Missing values

## Why Data Understanding is Important?

A Machine Learning model is only as good as the data provided to it. Understanding the dataset helps identify:
- Data quality issues
- Missing information
- Incorrect data types
- Potential preprocessing requirements
- Useful insights before modeling
 
## Key Concepts

### Rows
Each row represents a single observation or record.

### Columns
Each column represents a feature or attribute.
 
### Numerical Features

Examples:
- Age
- Salary
- Marks

### Categorical Features

Examples:
- Gender
- Department
- City

### Missing Values

Missing or unavailable information within the dataset.

### Duplicate Records

Repeated observations that may affect model performance.
