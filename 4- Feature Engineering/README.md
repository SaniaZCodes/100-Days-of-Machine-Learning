# Feature Engineering 🛠️

## What?

Feature Engineering is the process of converting raw data into useful data for Machine Learning models.

---

## Why?

✅ Improve model performance

✅ Handle missing values

✅ Convert categorical data

✅ Scale numerical data

✅ Create useful features

---

## Examples

Date of Birth → Age

Male/Female → 0/1

Salary Scaling

Handling Missing Values

---

## Includes

- Standardization
- Normalization
- Encoding
- Missing Values
- Outliers
- PCA

---

## Golden Line 🌟

Better Features = Better Models
