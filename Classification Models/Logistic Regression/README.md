# Logistic Regression

# Overview

Logistic Regression is one of the most fundamental Classification Algorithms in Machine Learning.

Despite the word "Regression" in its name, Logistic Regression is used for:

```text
Classification Problems
```

instead of:

```text
Regression Problems
```

It predicts the probability of a data point belonging to a particular class and then assigns a class label based on that probability.

---

# Classification vs Regression

## Regression

Predicts continuous values.

Examples:

```text
House Price Prediction

Salary Prediction

Temperature Prediction
```

Output:

```text
Numerical Value
```

---

## Classification

Predicts categories.

Examples:

```text
Pass / Fail

Spam / Not Spam

Disease / No Disease
```

Output:

```text
Class Label
```

---

# Perceptron

The Perceptron is the simplest Binary Classification Algorithm.

It creates a Decision Boundary that separates:

```text
Class 0

and

Class 1
```

using a linear equation.

---

## Working of Perceptron

Step 1:

```text
z = wx + b
```

Step 2:

Apply a threshold.

```text
z > 0
↓
1

z < 0
↓
0
```

---

# Decision Boundary

A Decision Boundary is a line (or hyperplane) that separates different classes.

Example:

```text
Fail Students
--------------------
Pass Students
```

The separating line is called the Decision Boundary.

---

# Limitation of Perceptron

Suppose:

```text
Student A = 70 Marks

Student B = 99 Marks
```

Perceptron predicts:

```text
70 → 1

99 → 1
```

Both belong to Class 1.

However, the Perceptron cannot tell:

```text
How confident is the prediction?
```

---

# Why Logistic Regression?

Logistic Regression improves the Perceptron by predicting:

```text
Probability
```

instead of directly predicting:

```text
0 or 1
```

Example:

```text
70 Marks → 0.72

99 Marks → 0.99
```

Now we know which prediction is more confident.

---

# Sigmoid Function

The Sigmoid Function is the heart of Logistic Regression.

It converts any real number into a value between:

```text
0 and 1
```

---

## Formula

```text
σ(z) = 1 / (1 + e^(-z))
```

---

## Purpose

Convert:

```text
Any Number
```

into:

```text
Probability
```

---

## Example

```text
z = -10
↓
0.000

z = 0
↓
0.5

z = 10
↓
0.999
```

---

# Final Prediction

The probability generated by Sigmoid is converted into a class label.

Typically:

```text
Probability ≥ 0.5
↓
Class 1

Probability < 0.5
↓
Class 0
```

---

# Logistic Regression Workflow

```text
Input Data
↓
Linear Equation

z = wx + b

↓
Sigmoid Function

↓
Probability

↓
Class Prediction
```

---

# Loss Function

A Loss Function measures how good or bad the predictions are.

---

## Linear Regression

Uses:

```text
Mean Squared Error (MSE)
```

---

## Logistic Regression

Uses:

```text
Binary Cross Entropy

(Log Loss)
```

---

# Binary Cross Entropy

Binary Cross Entropy gives:

### Good Prediction

```text
Actual = 1

Prediction = 0.99
```

Result:

```text
Low Loss
```

---

### Bad Prediction

```text
Actual = 1

Prediction = 0.01
```

Result:

```text
High Loss
```

---

# Maximum Likelihood Estimation (MLE)

Logistic Regression tries to make the correct class as probable as possible.

Example:

```text
Actual = 1

Prediction = 0.95
```

Better than:

```text
Actual = 1

Prediction = 0.20
```

This concept is called:

```text
Maximum Likelihood Estimation
```

---

# Derivative of Sigmoid

Gradient Descent requires the derivative of the Sigmoid function.

---

## Formula

```text
σ'(z)

=
σ(z) × (1 - σ(z))
```

---

## Purpose

The derivative provides the slope required for Gradient Descent to update model parameters.

---

# Gradient Descent

Gradient Descent is an optimization algorithm used to reduce loss.

---

## Workflow

```text
Prediction
↓
Loss
↓
Derivative
↓
Gradient Descent
↓
Update Weights
↓
Better Predictions
```

---

# Binary Classification

Standard Logistic Regression is used for Binary Classification.

Examples:

```text
Spam / Not Spam

Pass / Fail

Disease / No Disease
```

Uses:

```text
Sigmoid Function
```

---

# Softmax Regression

Problem:

```text
More than 2 Classes
```

Example:

```text
Cat

Dog

Horse
```

---

Solution:

```text
Softmax Regression
```

Also called:

```text
Multinomial Logistic Regression
```

---

## Example

```text
Cat   → 0.75

Dog   → 0.15

Horse → 0.10
```

Prediction:

```text
Cat
```

---

# Sigmoid vs Softmax

| Feature | Sigmoid | Softmax |
|----------|----------|----------|
| Classification Type | Binary | Multi-Class |
| Classes | 2 | More than 2 |
| Output | Probability | Probability Distribution |

---

# Polynomial Logistic Regression

Normal Logistic Regression creates:

```text
Linear Decision Boundary
```

---

Sometimes data is non-linear.

Solution:

```text
Polynomial Features
```

---

## Example

Original Feature:

```text
x
```

Polynomial Features:

```text
x

x²

x³
```

---

Result:

```text
Curved Decision Boundary
```

instead of a straight line.

---

# Regularization

Regularization helps prevent:

```text
Overfitting
```

by controlling model complexity.

---

```text
L2 Regularization
```

```python
penalty='l2'
```

---

# Lasso Logistic Regression

Uses:

```text
L1 Regularization
```

```python
penalty='l1'
```

---

# Elastic Net Logistic Regression

Uses:

```text
L1 + L2 Regularization
```

---

# Hyperparameter C

The most important Logistic Regression hyperparameter.

---

## Definition

```text
C = 1 / λ
```

where:

```text
λ = Regularization Strength
```

---

## Small C

```text
Strong Regularization
```

More control.

---

## Large C

```text
Weak Regularization
```

More freedom.

---

# Important Hyperparameters

## penalty

Controls regularization type.

```python
penalty='l1'
penalty='l2'
penalty='elasticnet'
```

---

## C

Controls regularization strength.

```python
C=1.0
```

---

## max_iter

Maximum number of iterations for optimization.

```python
max_iter=1000
```

---

## solver

Optimization algorithm.

Examples:

```python
solver='lbfgs'

solver='liblinear'

solver='saga'
```

# sklearn Implementation

## Basic Logistic Regression

```python
from sklearn.linear_model import LogisticRegression

model = LogisticRegression()

model.fit(X_train, y_train)

y_pred = model.predict(X_test)
```

---

## Predict Probabilities

```python
y_prob = model.predict_proba(X_test)
```

---

# Ridge Logistic Regression

```python
from sklearn.linear_model import LogisticRegression

model = LogisticRegression(
    penalty='l2',
    C=1.0,
    max_iter=1000
)

model.fit(X_train, y_train)
```

---

# Lasso Logistic Regression

```python
from sklearn.linear_model import LogisticRegression

model = LogisticRegression(
    penalty='l1',
    solver='liblinear',
    C=1.0,
    max_iter=1000
)

model.fit(X_train, y_train)
```

---

# Elastic Net Logistic Regression

```python
from sklearn.linear_model import LogisticRegression

model = LogisticRegression(
    penalty='elasticnet',
    solver='saga',
    l1_ratio=0.5,
    C=1.0,
    max_iter=1000
)

model.fit(X_train, y_train)
```

---

# Logistic Regression Using Gradient Descent

```python
from sklearn.linear_model import SGDClassifier

model = SGDClassifier(
    loss='log_loss',
    penalty=None,
    learning_rate='constant',
    eta0=0.01,
    max_iter=1000,
    random_state=42
)

model.fit(X_train, y_train)

y_pred = model.predict(X_test)
```

# Advantages

✅ Easy to understand and implement

✅ Fast training

✅ Works well for binary classification

✅ Produces probability outputs

✅ Supports regularization

✅ Interpretable model

---

# Limitations

❌ Assumes a linear decision boundary

❌ Struggles with highly complex relationships

❌ Sensitive to outliers

❌ May require feature engineering for non-linear problems

# Interview Questions

## What is Logistic Regression?

Logistic Regression is a classification algorithm that predicts probabilities and assigns class labels.

---

## Why do we use the Sigmoid Function?

To convert linear outputs into probabilities between 0 and 1.

---

## What is Binary Cross Entropy?

The loss function used in Logistic Regression.

---

## What is the difference between Sigmoid and Softmax?

Sigmoid is used for binary classification while Softmax is used for multi-class classification.

---

## What does C represent?

C is the inverse of regularization strength.

---

## What happens when C decreases?

Regularization becomes stronger.

---

## What happens when C increases?

Regularization becomes weaker.

---

## Which regularization techniques can be used with Logistic Regression?

```text
Ridge (L2)

Lasso (L1)

Elastic Net (L1 + L2)
```

# Summary

Logistic Regression is a powerful and widely used classification algorithm that predicts probabilities using the Sigmoid Function. It uses Binary Cross Entropy as its loss function and Gradient Descent for optimization. For multi-class problems, Logistic Regression can be extended using Softmax Regression. Regularization techniques such as Ridge, Lasso, and Elastic Net can further improve model generalization and reduce overfitting.
